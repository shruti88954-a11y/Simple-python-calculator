# 🧮 Simple Python Calculator

A beginner-friendly, clean, and interactive command-line calculator built using pure Python. 

## ✨ Features
- **Basic Arithmetic:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- **Error Handling:** Features a safety check to prevent program crashes during **Division by Zero**.
- **Input Validation:** Alerts the user if an invalid operator or character is entered.
